Optional photos for the website. Drop JPG files here with these exact names:

  station.jpg   wide photo for the band on the home page (landscape, at least 1600 px wide)
  login.jpg     tall or square photo for the left side of the sign-in page (at least 900 px)

If a file is missing, the site shows its built-in artwork instead, so nothing breaks.
Only use photos you took yourself, photos you have written permission to use,
or free stock photos (Unsplash, Pexels) - and keep a note of where each one came from.
